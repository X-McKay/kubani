# Tool contracts

One file per tool server, `<server>.json`: what the server answered to MCP `tools/list`
(name, description, input and output schema), the effect the operator assigns
(`remote_read` or `remote_write`), the image it was captured from and the digest of the
container's flags.

The files are generated by `just mcp contract <server>` and reviewed like any other
change. Never edit one by hand: the feed refuses a file whose `configDigest` or image
differs from the committed manifest, so a changed flag or image needs a new capture.
See [mcp-backend-registry.md](../../../docs/infrastructure/configuration/mcp-backend-registry.md).
