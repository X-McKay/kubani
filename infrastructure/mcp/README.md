# MCP declaration fields

V1 declarations use the `container-sse-v1` profile. `workload.secretEnv` is optional in effect (use an empty list when no environment credentials are required). Each item names an environment variable and a Kubernetes Secret key reference:

```yaml
secretEnv:
  - name: API_TOKEN
    secretKeyRef:
      name: example-mcp
      key: API_TOKEN
```

Declare the corresponding encrypted manifest in `secrets`. Registry definitions contain references; Secret values remain in the referenced SOPS manifests. The schema rejects extra fields in both the environment item and `secretKeyRef`.

`bootstrap.sqlSha256` and generated inventory file digests use `sha256:<64 lowercase hex characters>`. The bootstrap value must equal the actual SQL content digest. A changed SQL digest requires a reviewed bootstrap revision change. Rendering calculates inventory digests from the exact generated bytes.

The scaffold leaves `secretEnv`, `secrets` and `upstreams` empty; add only the explicit dependencies that the backend requires. Complete every `REQUIRED` placeholder before rendering.
