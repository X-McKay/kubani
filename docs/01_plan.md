# Hybrid Architecture Execution Plan

## Executive Summary

Transform kubani's agent system from a complex Python-centric architecture to a **Skills-First + SOPs** hybrid that prioritizes:
- **Simplicity**: Markdown-based skills and workflows instead of Python classes
- **Testability**: Local skill validation and SOP simulation without deployment
- **Continuous Learning**: Preserve Voyager-style Explorer → Skill → Healer loop
- **Ecosystem Compatibility**: Agent Skills spec for Claude Code, API, and community
- **A2A Protocol Alignment**: Skills complement existing A2A capability discovery

## Protocol Alignment: A2A + Agent Skills + MCP

### Terminology Clarification

There are three complementary protocols in play:

| Protocol | Purpose | Format | kubani Usage |
|----------|---------|--------|--------------|
| **[A2A](https://github.com/a2aproject/A2A)** (Google) | Agent-to-agent communication & discovery | JSON-RPC + AgentCard | `core_agents/communication/a2a.py` - existing |
| **[Agent Skills](https://agentskills.io)** (Anthropic) | Procedural knowledge for agents | Markdown SKILL.md | NEW: `skills/` directory |
| **[MCP](https://modelcontextprotocol.io)** (Anthropic) | Tool/resource access | JSON-RPC | Existing: kubernetes-mcp-server |

### How They Work Together

```
┌─────────────────────────────────────────────────────────────────┐
│                        AGENT DISCOVERY                          │
│  A2A AgentCard: "k8s-monitor CAN diagnose pods, remediate..."  │
│  → Other agents discover capabilities via A2A protocol         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                     PROCEDURAL KNOWLEDGE                        │
│  Agent Skills SKILL.md: "HOW to diagnose CrashLoopBackOff..."  │
│  → Loaded into agent context when executing capability         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                         TOOL EXECUTION                          │
│  MCP: kubernetes-mcp-server/pods_delete, pods_log, etc.        │
│  → Skills reference MCP tools for actual execution             │
└─────────────────────────────────────────────────────────────────┘
```

### Integration Points

1. **A2A AgentCapability → Skill Mapping**


3. **A2A Client Invoking Skills**
   ```python

       query="pod-crashloop-remediation",

   ```

## Kubernetes Deployment: Skills Storage & Approval

### The Challenge

When agents run as K8s pods (not in an IDE), they don't have persistent filesystem access. Skills need to be:
1. **Stored persistently** - survive pod restarts
2. **Version controlled** - track changes, enable rollback
3. **Reviewable** - human approval before activation

### Solution: GitOps-Based Skill Management

```
┌─────────────────────────────────────────────────────────────────┐
│                    SKILL PROPOSAL FLOW                          │
```

```python
# federated/explorer.py
import httpx
import base64

class ExplorerAgent:
    async def propose_skill(self, analysis: IncidentAnalysis) -> str:
        """Generate SKILL.md and create GitHub PR."""

        # Generate skill content
        skill_content = await self._generate_skill_markdown(analysis)
        skill_id = f"proposed-{analysis.signature[:8]}"

        # Create branch and file via GitHub API
        async with httpx.AsyncClient() as client:
            # Create branch
            branch_name = f"skill/{skill_id}"
            await self._create_branch(client, branch_name)

            # Create SKILL.md file
            file_path = f"skills/proposed/k8s/{skill_id}/SKILL.md"
            await client.put(
                f"{GITHUB_API}/repos/{REPO}/contents/{file_path}",
                headers={"Authorization": f"Bearer {GITHUB_TOKEN}"},
                json={
                    "message": f"feat(skills): Propose {skill_id}",
                    "content": base64.b64encode(skill_content.encode()).decode(),
                    "branch": branch_name,
                },
            )

            # Create PR
            pr = await client.post(
                f"{GITHUB_API}/repos/{REPO}/pulls",
                headers={"Authorization": f"Bearer {GITHUB_TOKEN}"},
                json={
                    "title": f"🆕 Skill Proposal: {skill_id}",
                    "body": self._format_pr_body(analysis),
                    "head": branch_name,
                    "base": "main",
                },
            )

        # Notify Discord
        await self.discord.post(
            f"**New Skill Proposed**\n"
            f"ID: `{skill_id}`\n"
            f"PR: {pr.json()['html_url']}\n"
            f"Based on: {len(analysis.incidents)} incidents"
        )

        return pr.json()["html_url"]
```

### 1.4 Implement UnifiedSkillLibrary

Create `agents/core/src/core_agents/skills/unified.py`:

```python
"""
UnifiedSkillLibrary - bridges filesystem skills with Qdrant search.

Skills are authored as markdown (source of truth) and synced to Qdrant
for semantic search. This enables:
- Edit skills in markdown, no code changes
- Semantic search for skill matching
- Automatic sync on startup or file change
"""

import hashlib
from pathlib import Path
from dataclasses import dataclass
import yaml
import frontmatter

from qdrant_client import AsyncQdrantClient
from qdrant_client.models import PointStruct, VectorParams

@dataclass
class AgentSkill:
    """Agent Skills format representation."""
    name: str
    description: str
    path: Path
    metadata: dict
    body: str  # Full markdown body

    @property
    def id(self) -> str:
        """Generate stable ID from path."""
        return self.path.parent.name

    @property
    def domain(self) -> str:
        return self.metadata.get("domain", "general")

    @property
    def category(self) -> str:
        return self.metadata.get("category", "general")

    @property
    def requires_approval(self) -> bool:
        return self.metadata.get("requires-approval", False)

    @property
    def confidence(self) -> float:
        return self.metadata.get("confidence", 0.5)

    def get_searchable_text(self) -> str:
        """Text for embedding generation."""
        return f"{self.name} {self.description}"


class UnifiedSkillLibrary:
    """
    Unified skill library that:
    1. Reads skills from filesystem (Agent Skills format)
    2. Indexes them in Qdrant for semantic search
    3. Provides search interface for agents
    """

    def __init__(
        self,
        skills_dir: Path,
        qdrant_url: str,
        embedding_model: str = "text-embedding-3-small",
    ):
        self.skills_dir = skills_dir
        self.qdrant_url = qdrant_url
        self.embedding_model = embedding_model
        self._skills_cache: dict[str, AgentSkill] = {}
        self._qdrant: AsyncQdrantClient | None = None

    async def sync(self) -> list[str]:
        """
        Sync filesystem skills to Qdrant.

        Returns list of skill IDs that were added/updated.
        """
        synced = []

        for skill_path in self.skills_dir.rglob("SKILL.md"):
            skill = self._load_skill(skill_path)
            if skill:
                await self._index_skill(skill)
                self._skills_cache[skill.id] = skill
                synced.append(skill.id)

        return synced

    def _load_skill(self, path: Path) -> AgentSkill | None:
        """Load a SKILL.md file into AgentSkill."""
        try:
            post = frontmatter.load(path)
            return AgentSkill(
                name=post.metadata.get("name", path.parent.name),
                description=post.metadata.get("description", ""),
                path=path,
                metadata=dict(post.metadata),
                body=post.content,
            )
        except Exception as e:
            logger.warning(f"Failed to load {path}: {e}")
            return None

    async def _index_skill(self, skill: AgentSkill) -> None:
        """Add/update skill in Qdrant."""
        embedding = await self._embed(skill.get_searchable_text())

        point = PointStruct(
            id=self._skill_id_to_uuid(skill.id),
            vector=embedding,
            payload={
                "skill_id": skill.id,
                "name": skill.name,
                "description": skill.description,
                "domain": skill.domain,
                "category": skill.category,
                "path": str(skill.path),
                "requires_approval": skill.requires_approval,
                "confidence": skill.confidence,
            },
        )

        await self._get_qdrant().upsert(
            collection_name="skills",
            points=[point],
        )

    async def search(
        self,
        query: str,
        domain: str | None = None,
        limit: int = 5,
    ) -> list[AgentSkill]:
        """
        Semantic search for matching skills.

        Args:
            query: Natural language description of situation
            domain: Filter by domain (k8s, news, general)
            limit: Max results

        Returns:
            Matching skills sorted by relevance
        """
        embedding = await self._embed(query)

        filter_conditions = None
        if domain:
            filter_conditions = {"domain": domain}

        results = await self._get_qdrant().search(
            collection_name="skills",
            query_vector=embedding,
            limit=limit,
            query_filter=filter_conditions,
        )

        skills = []
        for result in results:
            skill_id = result.payload["skill_id"]
            if skill_id in self._skills_cache:
                skills.append(self._skills_cache[skill_id])
            else:
                # Load from disk if not cached
                path = Path(result.payload["path"])
                skill = self._load_skill(path)
                if skill:
                    skills.append(skill)

        return skills

    async def get(self, skill_id: str) -> AgentSkill | None:
        """Get skill by ID."""
        return self._skills_cache.get(skill_id)
```

```python
# agents/core/src/core_agents/skills/local_runner.py
"""
LocalRunner - Test skills locally without Temporal/K8s.

Allows running agents locally with mocked MCP tools.
"""
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Callable, Dict
import asyncio
import yaml

@dataclass
class MockMCPClient:
    """Mock MCP client for testing."""
    name: str
    tools: Dict[str, Callable] = field(default_factory=dict)

    async def call_tool(self, tool_name: str, params: Dict[str, Any]) -> Any:
        if tool_name not in self.tools:
            raise ValueError(f"Tool not mocked: {tool_name}")
        handler = self.tools[tool_name]
        if asyncio.iscoroutinefunction(handler):
            return await handler(params)
        return handler(params)


class LocalRunner:
    """
    Run skills locally with mocked dependencies.

    Example:
        runner = LocalRunner(
            skills_dir="skills",
            mcp_mocks={
                "kubernetes": {
                    "pods_list": lambda p: [{"name": "pod-1", "status": "Running"}],
                    "pods_delete": lambda p: {"success": True},
                },
            },
        )

        result = await runner.execute_skill(
            "k8s/remediation/restart-crashloop",
            context={"POD_NAME": "nginx-123", "NAMESPACE": "default"},
        )
        assert result.success
    """

    def __init__(
        self,
        skills_dir: str | Path = "skills",
        mcp_mocks: dict[str, dict[str, Callable]] | None = None,
    ):
        from .loader import SkillLoader
        from .executor import SkillExecutor

        self.skill_loader = SkillLoader(skills_dir)
        self.mcp_registry = self._build_mock_registry(mcp_mocks or {})
        self.skill_executor = SkillExecutor(self.mcp_registry)

    def _build_mock_registry(self, mcp_mocks: dict) -> dict[str, MockMCPClient]:
        return {
            name: MockMCPClient(name=name, tools=tools)
            for name, tools in mcp_mocks.items()
        }

    async def execute_skill(self, skill_path: str, context: dict[str, Any]):
        """Execute a skill with mocked MCP tools."""
        skill = self.skill_loader.load_skill(skill_path)
        return await self.skill_executor.execute_skill(skill, context)

    async def run_test_scenarios(self, skill_path: str) -> dict:
        """Run all test scenarios from skill's test.yaml."""
        skill_dir = Path(self.skill_loader.skills_dir) / skill_path
        test_file = skill_dir / "test.yaml"

        if not test_file.exists():
            return {"error": "No test.yaml found", "passed": 0, "failed": 0}

        test_config = yaml.safe_load(test_file.read_text())
        results = []

        for scenario in test_config.get("scenarios", []):
            # Configure mocks from scenario
            self._configure_mocks(scenario.get("mocks", {}))

            # Execute skill
            try:
                result = await self.execute_skill(skill_path, scenario.get("context", {}))
                expected = scenario.get("expected", {})
                passed = result.success == expected.get("success", True)
            except Exception as e:
                passed = False
                result = {"error": str(e)}

            results.append({
                "name": scenario["name"],
                "passed": passed,
                "result": result,
            })

        return {
            "total": len(results),
            "passed": sum(1 for r in results if r["passed"]),
            "failed": sum(1 for r in results if not r["passed"]),
            "results": results,
        }

    def _configure_mocks(self, mocks: dict[str, Any]):
        """Update mock responses from test scenario."""
        for tool_path, mock_response in mocks.items():
            server_name, tool_name = tool_path.split(".", 1)
            if server_name in self.mcp_registry:
                self.mcp_registry[server_name].tools[tool_name] = lambda p, r=mock_response: r
```

```python
"""
SOPExecutor - runs Strands SOPs using an AI agent.

SOPs are loaded as agent context, and the agent executes steps
using available MCP tools. The executor tracks progress and
validates constraints.
"""

import frontmatter
from pathlib import Path
from dataclasses import dataclass
from strands import Agent

@dataclass
class SOPResult:
    """Result of SOP execution."""
    sop_name: str
    success: bool
    steps_completed: list[str]
    outputs: dict
    errors: list[str]

class SOPExecutor:
    """Execute SOPs using an AI agent."""

    def __init__(
        self,
        sops_dir: Path,
        agent: Agent,
        skill_library: UnifiedSkillLibrary,
    ):
        self.sops_dir = sops_dir
        self.agent = agent
        self.skill_library = skill_library

    def load_sop(self, name: str) -> str:
        """Load SOP content by name."""
        sop_path = self.sops_dir / f"{name}.sop.md"
        if not sop_path.exists():
            raise FileNotFoundError(f"SOP not found: {name}")

        post = frontmatter.load(sop_path)
        return post.content

    async def execute(
        self,
        sop_name: str,
        parameters: dict,
    ) -> SOPResult:
        """
        Execute an SOP with given parameters.

        The agent receives the SOP as context and executes each step,
        using MCP tools and skills as needed.
        """
        sop_content = self.load_sop(sop_name)

        prompt = f"""
Execute this Standard Operating Procedure with the given parameters.

# SOP
{sop_content}

# Parameters
{yaml.dump(parameters)}

# Instructions
1. Follow each step in order
2. Respect MUST/SHOULD/MAY constraints
3. Use available MCP tools for actions
4. Search skill library for matching skills when needed
5. Track progress and report results

Begin execution.
"""

        # Execute with agent
        result = await self.agent.run(prompt)

        return SOPResult(
            sop_name=sop_name,
            success=self._parse_success(result),
            steps_completed=self._parse_steps(result),
            outputs=self._parse_outputs(result),
            errors=self._parse_errors(result),
        )
```

## Summary of Changes

### k8s-monitor

| Component | Before | After |
|-----------|--------|-------|
| Skills | Python classes in `federated/skills.py` | Markdown in `skills/k8s/*/SKILL.md` |
| Workflows | Python in `workflows.py` | SOPs in `sops/k8s/*.sop.md` |
| Swarm | 6 Python agents | Removed (SOPs handle this) |
| Federated | 3 agents with Python skills | 3 agents with markdown skills |
| Temporal | Complex workflows | Simple SOP scheduler |
| Testing | Deploy to test | Local skill/SOP validation |

### news-monitor

| Component | Before | After |
|-----------|--------|-------|
| Skills | Implicit in agent code | Markdown in `skills/news/*/SKILL.md` |
| Workflows | Python in `workflows.py` | SOPs in `sops/news/*.sop.md` |
| Domain Agents | 5 Python agents | 5 agents using skills |
| Federated | 1 agent (NewsExplorer) | Updated to propose via GitHub PR |
| Temporal | 7 complex workflows | Simple SOP scheduler |

### Cross-Cutting

| Component | Before | After |
|-----------|--------|-------|
| A2A | AgentCapability → Python execution | AgentCapability → Skill lookup → execution |
| Skill Storage | Qdrant only | Git (source) + ConfigMap + Qdrant (search) |
| Skill Proposals | N/A | Explorer → GitHub PR → Human review → Flux sync |
| Portability | kubani-only | Claude Code, Claude API, community |

### Development Workflow Comparison

**Before (Current):**
```bash
# 1. Edit Python skill class
vim agents/k8s-monitor/src/k8s_monitor/federated/skills.py

# 2. Run agent tests (requires mocking)
cd agents/k8s-monitor && pytest tests/

# 3. Build container
just build k8s-monitor

# 4. Push to registry
just push k8s-monitor v0.2.25

# 5. Update GitOps, wait for Flux
git commit... git push... wait...

# 6. Verify in cluster
kubectl logs -n ai-agents deployment/k8s-monitor

# Total: 15-30 minutes
```

**After (Target):**
```bash
# 1. Edit skill markdown
vim skills/k8s/remediation/restart-crashloop/SKILL.md

# 2. Test locally (instant feedback)
./scripts/test-skill.sh k8s/remediation/restart-crashloop

# 3. Sync to Qdrant (if running locally)
./scripts/sync-skills.sh

# 4. Commit (Flux syncs ConfigMap automatically)
git add skills/ && git commit -m "fix(skills): ..." && git push

# Total: 5-10 minutes
```
