# Plans

Implementation plans organized by lifecycle stage.

## Workflow

```
ideas/ → drafts/ → ready/ → active/ → completed/
```

## Folders

| Folder | What goes here | When to move out |
|--------|----------------|------------------|
| `ideas/` | Rough concepts, future possibilities, research, roadmaps | When you start writing a real plan |
| `drafts/` | Plans being written or reviewed | When approved for implementation |
| `ready/` | Approved plans waiting for bandwidth | When you start working on it |
| `active/` | Plans currently being implemented | When implementation is complete |
| `completed/` | Finished plans (don't delete) | Never - this is history |

## File Naming

Use: `YYYY-MM-DD-<descriptive-name>.md`

Example: `2026-01-24-auto-skill-development-design.md`

## For AI Tools

- **Starting work?** Check `active/` for the current plan
- **Planning something new?** Create in `drafts/` with date prefix
- **Finished?** Move plan from `active/` to `completed/`
- Only ONE plan per feature should be in `active/` at a time
