# Platform release records

Change records for the platform profile of
[the release process](../release-process.md): Traefik, Authentik,
PostgreSQL, Longhorn, agentgateway (once it exists), and host driver/OS
changes on any node.

vLLM and gpu-broker changes use the inference profile instead, and their
records live under `docs/infrastructure/inference/releases/`.

Name each record `YYYY-MM-DD-<change>.md`, using the
[change record template](../release-process.md#change-record-template).
