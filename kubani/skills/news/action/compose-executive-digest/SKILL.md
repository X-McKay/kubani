# Compose Executive Digest

Create a comprehensive, professionally-formatted news digest suitable for executive consumption.

## When to Use

- Daily news digest generation
- Weekly summary compilation
- Creating multi-section digests with research, tools, and company updates
- Keywords: digest, executive, summary, newsletter, briefing

## Prerequisites

- Articles have been processed with analyze-article skill
- Research papers analyzed (if including research section)
- Tool repos analyzed (if including spotlight section)
- Company articles filtered (if including company section)

## Input Schema

```json
{
  "articles": [...],
  "research_deepdives": [...],
  "tool_spotlights": [...],
  "company_updates": [...],
  "trends": {...},
  "digest_type": "daily",
  "period_hours": 24
}
```

## Actions

### Step 1: Validate and Prepare Content

1. Verify minimum content exists (at least 3 articles OR 1 research paper)
2. Sort articles by importance score descending
3. Limit research deep-dives to max 3
4. Limit tool spotlights to max 3
5. Filter company updates to top 5 by importance

### Step 2: Generate Executive Summary

Create a 2-4 paragraph summary that:
1. Opens with the most significant development
2. Provides context on why it matters
3. Mentions 2-3 secondary important items
4. Closes with a forward-looking statement or emerging theme

Use LLM with prompt:
```
Write an executive summary for AI practitioners covering the following developments:
[Top 5-7 articles by importance]

Requirements:
- Professional tone, no hype
- 2-4 paragraphs
- Embed source citations as [Source Name](url)
- Start with the most significant news
- End with what to watch next
```

### Step 3: Compose Research Deep-dives Section

For each paper in `research_deepdives` (max 3):

Format:
```markdown
### [Paper Title](arxiv_url)
**Authors**: Author list
**Key Finding**: Main claim in one sentence

[2-3 paragraph practitioner summary]

**Key Takeaways**:
- Takeaway 1
- Takeaway 2
- Takeaway 3

**Impact**: Impact assessment
```

### Step 4: Compose Tool Spotlight Section

For each repo in `tool_spotlights` (max 3):

Format:
```markdown
### [Repo Name](github_url) ⭐ star_count
**Language**: Primary language | **Topics**: topic1, topic2

[Spotlight summary - why it's worth checking out]

**Best For**: Target audience description
```

### Step 5: Compose Company Updates Section

Group by company, then for each:

Format:
```markdown
### Company Name
- [Article title](url) - Brief summary
- [Another article](url) - Brief summary
```

Companies to watch for: OpenAI, Anthropic, Google/DeepMind, Meta, Microsoft, NVIDIA, Hugging Face, Mistral, Cohere, xAI

### Step 6: Compose Trends Section (if trends provided)

Format:
```markdown
## Trend Watch

**Rising**: topic1 (↑ velocity%), topic2 (↑ velocity%)
**Emerging**: new_topic1, new_topic2
**Fading**: old_topic1, old_topic2

[Trend summary paragraph]
```

### Step 7: Compose Header and Footer

Header:
```markdown
# AI News Digest - {Month Day, Year}
*{Morning/Evening/Weekly} Edition | {n} articles from {n} sources*

---
```

Footer:
```markdown
---
*Generated by Kubani News Service | [Feedback](feedback_url)*
```

### Step 8: Assemble Full Digest

Order of sections:
1. Header
2. Executive Summary
3. Research Deep-dives (if any)
4. Tool Spotlights (if any)
5. Company Updates (if any)
6. Trend Watch (if trends provided)
7. Footer

### Step 9: Split for Discord

Discord has 2000 character limit. Split intelligently:
1. Never break mid-section if possible
2. Max 1900 chars per message (safety margin)
3. Add continuation indicator: `(continued...)`
4. Preserve markdown formatting

### Step 10: Build Output

Return:
- Complete digest object
- Array of Discord-ready message chunks
- List of sections actually included

## Output Schema

```json
{
  "digest": {
    "digest_id": "digest-abc12345",
    "created_at": "2026-01-27T07:00:00Z",
    "digest_type": "daily",
    "period_start": "2026-01-26T07:00:00Z",
    "period_end": "2026-01-27T07:00:00Z",
    "sections": {
      "executive_summary": "...",
      "research_deepdives": [...],
      "tool_spotlights": [...],
      "company_updates": {...},
      "trends": {...}
    },
    "metadata": {
      "article_count": 45,
      "source_count": 12,
      "papers_featured": 2,
      "tools_featured": 2
    }
  },
  "discord_messages": [
    "# AI News Digest - January 27, 2026\n*Morning Edition...",
    "## Research Deep-dives\n\n### Paper Title...",
    "## Tool Spotlights\n\n### repo-name..."
  ],
  "sections_included": ["executive_summary", "research_deepdives", "tool_spotlights", "company_updates"]
}
```

## Success Criteria

- [ ] Executive summary is coherent and professional
- [ ] All included sections properly formatted
- [ ] Citations embedded correctly
- [ ] Discord chunks are valid length
- [ ] Markdown renders correctly
- [ ] No duplicate content across sections

## Failure Handling

| Error Type | Handling Strategy |
|------------|-------------------|
| LLM summary fails | Use bullet-point fallback format |
| Empty sections | Omit section entirely |
| Content too long | Truncate less important items |
| No content at all | Return error with explanation |
